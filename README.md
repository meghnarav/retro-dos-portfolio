# retro-dos-portfolio

A lightweight, DOS/CRT-inspired terminal portfolio built with vanilla HTML, CSS, and JavaScript.

## Link
[https://meghnarav.github.io/retro-dos-portfolio/](https://meghnarav.github.io/retro-dos-portfolio/)

## Overview

* **Zero Build Pipeline:** Pure HTML5/CSS3/ES6 JavaScript. Works directly with just GitHub Pages.
* **DOS / BBS Aesthetics:** Custom CRT scanline styling, monochrome/palette accents, and VT-style UI hierarchy.
* **CLI & Keyboard Navigation:** Interactive command parsing, history traversal (`↑` / `↓`), tab autocomplete, and mapped function keys (`F2`–`F4`, `F6`-`F10`).
* **Accessible & Responsive:** Adapts to mobile screen sizes with an on-screen soft function bar; respects `prefers-reduced-motion`.

## Interactive Commands

| Command | Description |
| :--- | :--- |
| `help` / `ls` | Displays the list of available commands |
| `about` | Background and technical focus |
| `projects` | Selected backend and distributed systems projects |
| `skills` | Core languages, frameworks, and tools |
| `education` | University and degree overview |
| `achievements` | Competitions and open-source contributions |
| `contact` | Email and external profiles |
| `clear` | Clears the terminal screen buffer |
